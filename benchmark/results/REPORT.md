# Subgoal 指令跟随 Benchmark 实验报告

更新 2026-09-25。R2R-CE val_unseen 分层 200-set,子指令边界来自 FGR2R。三个系统方法代码均未改动(CA-Nav、AwareVLN 只加了轨迹导出):

- **FreeAskAgent**:零样本,JoyAI 观察 + Qwen3-VL-8B 决策;6 视角预览、无 navmesh。ORIG、重复 ORIG 与 GOAL-ONLY 是 2026-09-19 的旧版代码(起始朝向 v1-2),FLIP 与 PARAPHRASE(100 集)是 2026-09-25/26 的当前代码(起始朝向 v1-3),与 ORIG/GOAL-ONLY 不是同一版本。
- **CA-Nav**:零样本,离线 LLM 解析指令 + 价值图搜索;上游 exp1_nogate。原始解析用 GPT-4,PARAPHRASE 用 Qwen3-VL-8B 重新解析。
- **AwareVLN**:在 R2R 上 SFT 的 8B,官方 checkpoint。

所有数字由 `python -m benchmark.summarize` 从原始轨迹统一重算(`results/summary.json`)。

**指标**:SR 成功率;nDTW 整条轨迹与参考路线的贴合度;κ 两次运行成败落在同一批 episode 的程度(1 = 完全相同,0 = 与随机无异);p 为 McNemar 检验(SR 是否真的变了);Δ 为同一批 episode 上的配对差,**加粗 = 95% 区间不含 0**。

## 结论

**按机器人三定律判断**(见 `benchmark/README.md` §3;第一、第三定律目前不可测,只按第二定律"服从命令"比较):

| 系统 | 服从率(两次平均) | 冲突服从率(反转后照做) | WordEffect | 两次都照做 | 判定 |
|---|---|---|---|---|---|
| FreeAskAgent | 0.768 | 0.707 | +0.30 [0.24, 0.35] | 47/82 | 三者中最服从,但仍有 22% 反转命令被违抗 |
| AwareVLN | 0.677 | 0.439 | +0.18 [0.13, 0.24] | 31/82 | 较好,但一半以上明确命令被违抗 |
| CA-Nav | 0.457 | 0.268 | −0.01 [−0.02, 0.00] | 0/82 | 不服从:方向词对行为没有影响 |

两者都不合格(完全服从:冲突服从率 1.0、WordEffect ≈ +0.5)。

1. **三个系统解的是不同的题。** ORIG 下两两 κ ≈ 0,200 集里三个都成功的只有 10 集,至少一个成功的有 154 集。
2. **单条 episode 的成败很不稳定。** FreeAskAgent 同输入重跑、或 CA-Nav 只换解析器,都有 21–23% 的 episode 成败翻转(κ 0.26 / 0.40)。个例分析要先过这条噪声线。
3. **AwareVLN 是唯一真正读路线描述的系统**(GOAL-ONLY 后 nDTW、中间边界到达率大幅下降),对措辞改写基本稳健。
4. **CA-Nav 不读过程句,但对地标叫法敏感**:地标换描述后路线明显变差,SR 靠长搜索维持不变。
5. **FreeAskAgent(旧版)的指令响应主要体现在 STOP 时机**。另外旧版用的 v1-2 起始朝向与指令的第一句对不上(见 §2),这可能一直在拖累它的起步。
6. **服从命令(FLIP)**:FreeAskAgent 最服从(反转后 71% 照做),AwareVLN 其次(44%),CA-Nav 完全不看方向词(见 §2)。三者都没达到完全服从。

## 1. ORIG(原指令)

| 系统 | SR | SPL | nDTW | 路程 m | 步数 |
|---|---|---|---|---|---|
| FreeAskAgent | 0.255 | 0.195 | 0.366 | 18.5 | 142 |
| CA-Nav(GPT-4 解析) | 0.255 | 0.110 | 0.174 | 27.9 | 214 |
| CA-Nav(Qwen 解析) | 0.240 | 0.106 | 0.162 | 29.0 | 220 |
| AwareVLN | 0.625 | 0.538 | 0.647 | 13.1 | 110 |

- **噪声参照**:FreeAskAgent 两次 ORIG(47 集)SR 0.213 → 0.128,只有 3 集两次都成功,κ 0.26。CA-Nav 给定同一份解析基本是确定的,只换解析器(GPT-4 → Qwen)SR 0.255 → 0.240,但 κ 只有 0.40,近一半成功 episode 换了。AwareVLN 未重跑。
- **跨系统**:FreeAskAgent–CA-Nav κ −0.00、FreeAskAgent–AwareVLN 0.09、CA-Nav–AwareVLN 0.02。FreeAskAgent 与 CA-Nav SR 相同,成功的 episode 却只重合 13 集。
- CA-Nav nDTW 低,是因为每集平均走 28 m、200 多步在搜索。

## 2. FLIP(起点方向反转)

2026-09-24 重做。旧版 FLIP-k 反转的是路线中段的一句,只有走到那个转弯处的 episode 才能评分,三个系统各自可评的集合不同(18–35 集)且偏容易,已删除。

新版只反转**第一句**里的转弯指令,转弯发生在起点,每个系统的每一集都能评分:

- 从全量 val_unseen 选出 94 个候选,左右配平后 82 集(left 41、right 41),覆盖 11 个场景。条件:第一句只含一个 left/right,且是转弯指令(不是"桌子在你右边"这类地标方位);按 v1-3 起始朝向,参考路径在前 5 m 内朝该词方向转 45°–135°;反方向可通行。
- 起始朝向统一用 R2R-CE v1-3。FreeAskAgent 旧版一直用的 v1-2 朝向与指令对不上(第一句 "turn left/right" 与路径方向一致:v1-3 24/32,v1-2 6/26),82 集中有 67 集两者相差 > 45°。因此 ORIG 对照在同一批 82 集、同一朝向上重跑(`flip_orig`),不复用 200-set 的 ORIG。
- CA-Nav 的 FLIP 只改 GPT-4 解析中包含该方向词的那一条子指令里的这一个词,82 集全部可映射。
- 评分:每次运行的每一集归为按指令词转 / 反着转 / 直行 / 没离开起点,四类之和为 1;WordEffect = 两次运行平均跟随率 − 不看方向词时的期望(完全跟随约 +0.5,不看为 0)。

**结果**(82 集,每行四类之和为 1):

| 系统 | 运行 | 按指令词转 | 反着转 | 直行 | 没离开起点 | WordEffect | 两次同一侧 | 跟随率 left / right | SR |
|---|---|---|---|---|---|---|---|---|---|
| CA-Nav | ORIG | 0.646 | 0.268 | 0.085 | 0 | −0.006 [−0.015, 0.000] | 75/82 | 0.366 / 0.549 | 0.256 |
| | FLIP | 0.268 | 0.671 | 0.061 | 0 | | | | 0.171 |
| FreeAskAgent | ORIG | 0.829 | 0.134 | 0.037 | 0 | **+0.296** [0.241, 0.348] | 27/82 | 0.720 / 0.817 | 0.232 |
| | FLIP | 0.707 | 0.220 | 0.073 | 0 | | | | 0.122 |
| AwareVLN | ORIG | 0.915 | 0.073 | 0.012 | 0 | **+0.183** [0.128, 0.241] | 48/82 | 0.671 / 0.683 | 0.646 |
| | FLIP | 0.439 | 0.549 | 0.012 | 0 | | | | 0.463 |

- **CA-Nav 起步不看方向词**:WordEffect 为 0,91% 的集两次往同一侧走,37/82 条轨迹逐点相同。ORIG 下 65% "转对"是因为房间布局本来就引向那边,换了词它照走,所以 FLIP 下只剩 27%,两次都对 0 集。解析结果里对应的词 82 集都改了(每集只改一个词),是导航没用它,不是输入没改到。
- **偏右**:拿到 right 时跟随 0.549,拿到 left 时 0.366;因为它不看词,这反映的是它自己偏向右转。
- SR 0.256 → 0.171(McNemar p = 0.12,不显著)。
- **FreeAskAgent 最服从方向词**:反转后 71% 照新词转(AwareVLN 44%、CA-Nav 27%),WordEffect +0.30,区间与 AwareVLN 不重叠;两次都照做 47/82。不过原词下它的照做率(83%)反而低于 AwareVLN(92%)。SR 0.232 → 0.122(McNemar p = 0.064),到达终点的能力远低于 AwareVLN。FLIP 与记忆消融实验同时运行、共用服务(两组 FLIP 同时跑,负载相同)。
- **AwareVLN 读方向词,但只起一半作用**:原词下 92% 转对;反转后 44% 按新词转、55% 仍按原方向,WordEffect +0.18(完全跟随约 +0.5),两次都转对 31/82。起步方向大部分仍由场景决定(哪边有门、走廊)。左右无偏(0.671 / 0.683),旧版 FLIP 里看到的"偏左"没有复现。SR 0.646 → 0.463(McNemar p = 0.011),反转方向词确实伤害成功率;只有 6/82 条轨迹两次相同。

## 3. GOAL-ONLY(只保留最后一段子指令,对照 = 同批 ORIG,174 集)

| 指标 | FreeAskAgent | CA-Nav | AwareVLN |
|---|---|---|---|
| SR 原 → 只给目标 | 0.253 → 0.161 | 0.241 → 0.184 | 0.621 → 0.351 |
| κ / p | 0.38 / **0.011** | 0.15 / 0.20 | 0.22 / **<0.001** |
| ΔnDTW | +0.036 | +0.006 | **−0.172** |
| Δ路程 m | **−8.1** | −2.6 | −1.3 |
| 中间边界到达率 | 0.548 → 0.409 | 0.657 → 0.577 | 0.821 → 0.613 |

- **AwareVLN**:唯一一个去掉过程句后 nDTW 显著下降的系统,是真的按路线走,不是背路线;去掉路线就退化为搜索。
- **CA-Nav**:SR 下降不显著,nDTW 不变,本来就主要靠终点类别搜索。
- **FreeAskAgent**:路程减 8 m、步数减半、nDTW 反升:只剩一段子指令时 judge 很快判完成然后 STOP,SR 下降来自提前停止。
- 只给目标时的成功偏向短而直的 episode(CA-Nav 最明显);另有 AwareVLN 13 集、CA-Nav 20 集、FreeAskAgent 10 集只给目标反而成功。

## 5. 对 FreeAskAgent 的建议

1. 比较改动前后时,≤ 50 集的 SR 差异不看;SR 要同时报 κ / p 和重复 ORIG 的噪声参照(`metrics --compare`)。
2. 句子级 grounding 以 FLIP 的 WordEffect 为目标(理想值约 +0.5);judge 判第 k 段完成时应对照第 k 句的地标和动作,而不是按节奏推进。先查 v1-2 起始朝向对 FreeAskAgent ORIG 的影响。
3. GOAL-ONLY 显示 FreeAskAgent 的指令响应走的是"subgoal 数量 → STOP 时机",与 full-run 失败分析(91% 失败是 judge STOP)一致。
4. 若用检测或价值图,地标先归一到检测器熟悉的类别;建议 FreeAskAgent 补跑 PARAPHRASE 的 A1 + A4。

## 附:实现注意事项

- CA-Nav 运行时只读离线解析。FLIP / GOAL-ONLY 在 GPT-4 解析上改 / 删子指令;PARAPHRASE 用 Qwen3-VL-8B 按上游 prompt 重解析全部 1000 条,128 条首次格式不合格,带错误反馈重试后通过,无手工修改。
- 200-set 里有 5 集罗列式指令(ep 31/161/288/503/657),与其余分布不同,见 `docs/benchmark_data_review.md`。
- 复现:`python -m benchmark.summarize`;单组配对:`python -m benchmark.metrics --orig <A> --compare <B>`。
